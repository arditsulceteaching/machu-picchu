# Machu Picchu at Sunrise

A real-time, fully procedural Machu Picchu at sunrise, rendered with WebGPU in a single self-contained `index.html`.

**Live:** https://arditsulceteaching.github.io/machu-picchu/

Needs a WebGPU browser (recent Chrome or Edge). Mouse to look, W A S D to fly, E / Q up and down, 1–6 for viewpoints, Esc for the menu.
